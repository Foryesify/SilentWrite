# About SilentWrite

There are already plenty of mature Markdown editors out there — iA Writer, Ulysses, Nomo, and so on. I've tried a lot of them.

But none felt quite right. Each had its own shortcomings, and none gave me a setup I was truly comfortable with.

Some are paid. Some have messy interfaces. Some are paid *and* Mac-only. Others are basically VS Code — or worse.

iA Writer and Ulysses have decent design philosophies, but both are expensive. They're clearly built to make money.

I have reasons not to pay, too. Ulysses doesn't feel clean enough, and it only supports the Apple ecosystem.

iA Writer is even more extreme — it refuses UI animations and most customization options. That's going backwards, if you ask me.

A few years ago, while searching for something on Bing, I stumbled upon [Linho's](https://github.com/linho1219) blog.

He had built an app called Clear Writer, inspired by iA Writer. Clean interface, smooth experience — writing in it felt genuinely good.

I wanted to build a Markdown editor like that — something that gives *me* a great writing experience.

Writing doesn't really need a powerful tool. What it needs is an environment that doesn't distract you.

That's why I built SilentWrite. And that's what SilentWrite aims to be.

## Why SilentWrite

Built to be a writing app that:

- Is cross-platform with a solid web experience, including mobile
- Supports PWA, with good Safari support as a stand-in for iOS
- Doesn't force you to pay
- Keeps the UI minimal and clean — preferences are set up once at the start, then live in Settings (obsessive-detail-friendly)
- Offers backup on the web version
- Has an efficient, tidy file system with folders, files, and file passwords
- Supports cloud sync
- Sweats the details — cursor, scrollbar, selection, animations — all the way
- Supports transparent backgrounds
