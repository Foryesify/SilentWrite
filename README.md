# SilentWrite

If you're a diary keeper, a blogger or a writer, seeking for a free Markdown editor with a clean appearance and a smooth experience, SilentWrite might be an excellent choice for you. Among all popular Markdown editors, some are commercialized and too expensive to use, like Ulysses, iA Writer and Typora, and some are too functional to focus on essay writing, like VS Code and Obsidian.

## Why SilentWrite

Designed for offering a quiet, immersive environment, SilentWrite is a simple Markdown writing tool that enables you to think clearly when you're creating an essay. You can enjoy a smooth and distraction-free experience of writing in the SilentWrite Editor.

SilentWrite is an open-source project providing a series of simple but useful features. Your essays can be safely protected by setting a password. Your files can be easily exported by clicking a button. File organizing is also supported with the files & folders in SilentWrite Libary. What's more, all these features are totally free for you.

All the features include:

- Password protection, file organizing and essay exporting mentioned.
- Front matter YAML support.
- Simple, distraction-free experience and smooth interactions.
- Excellent UI Design, even better than some paid solutions.
- Customizable appearance.
- Well mobile touchscreen support.
- Cross-platform and Web & PWA supported.
- Local essay syncing based on file copying, only enables in app.
- Acrylic effect and transparency effect.
- Small app size and high-performance.
- Free and open-source.

## How SilentWrite Made It

At first, SilentWrite is just my personal project. I want to write my own essays in a clean environment, but I just don't want to pay for those expensive apps. 

SilentWrite used front-end tech stack to gain a smooth developing experience and cross-platform feature. CodeMirror makes it possible to build the core editor component. Vue provides the solution of architecting the whole project and state management. And Cursor accelerates the speed of development. Thanks to their developers.
